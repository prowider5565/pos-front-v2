# Payments API Documentation

Payment processing for all debt types and sales.

- **[PAYMENTS_API.md](PAYMENTS_API.md)** - Complete API reference

## 🎯 Overview

Comprehensive payment processing with direct and bulk payment support, FIFO distribution, and automatic status updates.

**Total Endpoints:** 13

## 📋 Endpoints

### Old Seller Debt Payments (4)
- Direct payment
- Bulk payment
- Get supplier payments
- Get debt payments

### Old Client Debt Payments (4)
- Direct payment
- Bulk payment
- Get client payments
- Get debt payments

### New Seller Debt Payments (3)
- Direct payment
- Bulk payment
- Get debt payments

### Sale Payments (2)
- Direct sale payment
- Bulk sale payment

## 🔑 Key Features

✅ Direct & bulk payments  
✅ FIFO distribution strategy  
✅ Multi-currency support  
✅ Multiple payment methods  
✅ Overpayment prevention  
✅ Automatic status updates

- **BANK_ACCOUNT**: Bank transfer
- **TRANSFER**: Money transfer
