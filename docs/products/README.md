# Products API Documentation

Product catalog, inventory batches, and categories.

## 📚 Documentation Files

- **[PRODUCTS_API.md](PRODUCTS_API.md)** - Complete API reference
- **[PRODUCTS_QUICK_REFERENCE.md](PRODUCTS_QUICK_REFERENCE.md)** - Quick reference guide

## 🎯 Overview

Complete product management with batch inventory tracking, category organization, and automatic debt creation.

**Total Endpoints:** 14

## 📋 Endpoints

### Products (6)
- List products by supplier
- List products for sale
- Create product
- Get product details
- Update product
- Delete product

### Batches (5)
- List batches
- Create batch (with auto debt)
- Get batch details
- Update batch
- Delete batch

### Categories (3)
- List categories
- Create category
- Update category

## 🔑 Key Features

✅ CRUD operations  
✅ Batch inventory tracking  
✅ Auto debt creation on import  
✅ Image management  
✅ Category organization  
✅ Soft delete  

## 📦 Product Types

- **KG**: Kilogram (weight)
- **PIECE**: Piece/Unit (count)
- **LITER**: Liter (volume)

## 🔗 Related APIs

- **Media API**: Image uploads
- **Debts API**: Auto debt creation
- **Sales API**: Inventory deduction
